Clone client

copy an entire client configuration to a new client
Please ensure you use a fully scoped PK and SK.
Read-only. Reads the source client and builds a clone plan. Nothing is created at this step.
This is the only part of the app that writes. Everything else performs read-only GETs. Capture and plan are safe; Apply creates real objects in the target tenant and cannot be rolled back via the API.

How it works

StageWhat happensWrites?
1. CaptureReads the source client's full configuration via CAT GETs.no
2. PlanProduces an ordered, inspectable JSON plan of every call needed to rebuild it. Downloadable.no
3. Dry runResolves every id placeholder and prints the exact calls that would be sent. No sockets opened.no
4. ApplyExecutes the plan, remapping every id as it goes, journalling each call to clone-runs/.YES
5. Clean upReverses the run as far as CAT allows — deletes what can be deleted, sets the rest Inactive. Partial: channels and processors can be neither deleted nor deactivated.YES

Capture shows exactly how much of a run would be reversible before you commit to it.
